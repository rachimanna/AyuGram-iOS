# AyuGram для iOS

Нативный iOS-порт [AyuGram4A](https://github.com/AyuGram/AyuGram4A) — Telegram-клиента с
режимом призрака, сохранением удалённых сообщений и историей правок.

Это не эмулятор, не обёртка APK и не WebView: приложение написано на Swift (SwiftUI + UIKit),
а с Telegram работает через **TDLib** — официальную библиотеку Telegram, тот же уровень, что
`ConnectionsManager`/`MessagesController` в Android-версии. Вся логика AyuGram
(`com.radolyn.ayugram`) переписана на Swift с теми же ключами настроек и схемой базы.

> Неофициальный проект. Не связан с командой AyuGram и с Telegram.

## Возможности

**Функции AyuGram**
- Режим призрака: не читать сообщения, не отправлять «в сети» и «печатает», авто-«офлайн»,
  «Читать после ответа», «Прочитать до сюда», отправка через отложку (+12 с)
- Сохранение удалённых сообщений (с медиа, реакциями, форматированием), метка 🧹,
  экран «Удалённые сообщения» для каждого чата
- История правок с просмотром всех версий
- Фильтры сообщений (regex) со встроенной проверкой шаблона
- Отключение рекламы, Local Premium (визуально), кнопка закрытия приложения
- AyuSync (тот же протокол, что на Android)
- Экран «Настройки AyuGram» с теми же разделами и пунктами, что на Android

**Telegram**
- Вход по номеру, коду, паролю 2FA, QR-коду; регистрация
- Список чатов: папки, архив, закреплённые, поиск, свайп-действия, онлайн-статус, «печатает…»
- Чат: текст с форматированием и ссылками, ответы, пересылка, редактирование, удаление,
  фото, видео, GIF, кружки, стикеры (WebP), файлы (QuickLook), голосовые (Opus), музыка,
  геопозиция, контакты, опросы, реакции, альбомы, служебные сообщения
- Отправка текста, фото (до 10 за раз) и файлов
- Запись голосовых сообщений с прослушиванием, перезаписью и повтором отправки при ошибке (M4A/AAC)
- Панель историй и просмотр фото/видео с переключением; отметки просмотра учитывают настройку «Не читать сообщения»
- Профили пользователей, групп и каналов; контакты; активные сеансы
- Светлая/тёмная/системная тема, 6 цветов акцента, размер текста
- Локальные уведомления и фоновое обновление
- Русский и английский интерфейс

## Требования

| | |
|---|---|
| Mac | macOS 14.5+ |
| Xcode | 16.0+ (Swift 5 language mode) |
| iPhone/iPad | iOS 17.0+ |
| Инструменты | [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`) |
| Telegram API | свои `api_id` и `api_hash` с [my.telegram.org](https://my.telegram.org/apps) |

Зависимости (подключаются автоматически через Swift Package Manager):
[TDLibKit](https://github.com/Swiftgram/TDLibKit) (TDLib 1.8.67, ~300 МБ бинарник),
[opus-swift](https://github.com/vector-im/opus-swift), [ogg-swift](https://github.com/vector-im/ogg-swift).

## Установка и настройка

```bash
git clone <ваш-репозиторий>/AyuGram-iOS.git
cd AyuGram-iOS
cp Config/Secrets.example.xcconfig Config/Secrets.xcconfig   # необязательно
xcodegen generate
open AyuGram.xcodeproj
```

`Config/Secrets.xcconfig` (не попадает в git):

```
AYU_BUNDLE_ID = com.yourname.ayugram     // уникальный Bundle ID
AYU_DEVELOPMENT_TEAM = ABCDE12345        // Team ID из Apple Developer
TG_API_ID = 1234567
TG_API_HASH = 0123456789abcdef0123456789abcdef
```

Если `TG_API_ID`/`TG_API_HASH` не заданы, приложение спросит их при первом запуске
и сохранит в Keychain.

## Запуск

1. Откройте `AyuGram.xcodeproj`, дождитесь загрузки пакетов (первый раз — несколько минут).
2. Выберите схему **AyuGram** и симулятор или подключённый iPhone.
3. ⌘R.

Тесты: ⌘U (схема AyuGram) — фильтры, настройки, база AyuGram, сохранение удалённых и правок.

## Сборка

Через Xcode: **Product → Archive**.

Без Mac — через GitHub Actions (`.github/workflows/ios.yml`): при каждом push в `main`
собирается **неподписанный** `AyuGram-unsigned.ipa` и прогоняются тесты. Скачать — в
Actions → последний запуск → Artifacts. Ключи API можно передать через секреты
репозитория `TG_API_ID` и `TG_API_HASH` (иначе приложение спросит их при запуске).

Командная строка на Mac:

```bash
xcodegen generate
xcodebuild -project AyuGram.xcodeproj -scheme AyuGram -configuration Release \
  -sdk iphoneos -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build
```

## Подпись (signing)

- **Свой Apple ID в Xcode**: Signing & Capabilities → выберите Team (или задайте
  `AYU_DEVELOPMENT_TEAM`), уникальный `AYU_BUNDLE_ID`. Бесплатный аккаунт — подпись на 7 дней.
- **Неподписанный IPA из CI**: подпишите и установите через AltStore, SideStore,
  Sideloadly, TrollStore или ваш собственный инструмент подписи.
- Фоновое обновление требует capability **Background Modes → Background fetch / processing**
  (уже прописано в Info.plist через `project.yml`).

## Перенесённые функции

Полная таблица — в [docs/PORTING.md](docs/PORTING.md#4-перенос-функций-ayugram).
Коротко: все пункты «Настроек AyuGram» Android-версии присутствуют и работают: режим призрака

## Функции, которые нельзя перенести полностью

| Функция | Причина | Что сделано вместо |
|---|---|---|
| AyuGram Push Service (постоянный фон) | iOS запрещает постоянные фоновые соединения; push Telegram доступны только официальным приложениям | Фоновое обновление (`BGAppRefreshTask`) + локальные уведомления |
| «Не отправлять печатает» при загрузке медиа | TDLib сам шлёт статус загрузки, бинарник TDLib не патчится | Текстовый «печатает» полностью скрыт; для медиа — ограничение |
| «Не читать» — локальное прочтение | В TDLib нет «локального прочтения» | Свой маркер прочтения: счётчик скрывается только в этом приложении |
| Local Premium | Premium проверяется сервером | Значок и UI, как и на Android |
| Сохранение медиа удалённого сообщения | Если медиа не было загружено, его уже нет на сервере | Копируется, если файл был загружен до удаления |
| Официальные ключи Telegram | Не принадлежат проекту | Свои `api_id`/`api_hash` |
| Кнопка «истечь» у TTL-медиа | Не реализовано в этом этапе | — |

## Известные ограничения (этап 1)

- TGS-стикеры воспроизводятся через Lottie, GIF/MP4 — прямо в чате; проверка новой реализации на устройстве ещё требуется.
- Стикеры WebM/VP9 и анимированные эмодзи пока показываются статично.
- Нет записи видеосообщений, звонков, публикации историй, трансляций, мини-приложений, ботовых клавиатур.
- Просмотр историй и запись голосовых добавлены в исходники; сборка и проверка на iPhone ещё требуются.
- Один аккаунт (база AyuGram уже хранит `userId` для мультиаккаунта).
- Редактирование сохраняет только текст (форматирование при правке сбрасывается).
- Темы форумов отображаются общей лентой.
- Сервер AyuSync (`ayusync.cloud`) может быть недоступен — адрес меняется в настройках.

### Размер сборки

CI прикладывает `ipa-size.json` к IPA и выводит размер сжатого IPA, распакованного
приложения и крупнейших файлов. Размер скачивания и размер установленного приложения
различаются. Минимум 70 МБ пока не обеспечен; размер не является проверкой наличия
звонков, историй или других функций. Для них нужны отдельные реализации и проверки.

Локальный отчёт: `python3 scripts/ipa_report.py AyuGram-unsigned.ipa --output ipa-size.json`.
